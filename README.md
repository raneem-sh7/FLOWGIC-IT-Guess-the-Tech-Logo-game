# Guess the Tech Logo

Setup for the FLOWGIC IT student technology team’s React application.

## Start development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Project folders

- `src/components` — reusable UI components
- `src/pages` — page-level views
- `src/data` — local TypeScript data
- `src/config` — application configuration
- `src/hooks` — reusable React hooks
- `src/utils` — shared utilities
- `src/assets` — imported assets
- `public/logos` — static logo assets
- `public/sounds` — static sound assets
